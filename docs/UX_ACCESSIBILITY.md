# UI/UX & Accessibility Specification

## Metaphor
Audiobook / teleprompter — primary action is listen, not chat.

## Tokens
- Background `#14171A`
- Text `#F5F1E8`
- Highlight `#E8A33D` (with non-color marker)
- Typography: Atkinson Hyperlegible (or system fallback), 18–20px in narration stage
- Visible focus always; respect `prefers-reduced-motion`

## Acceptance checklist
- Keyboard-only operation
- Accessible names on controls
- `aria-live` audio status
- Color never sole meaning carrier
- Zoom-safe layout
- Manual NVDA pass on Windows
